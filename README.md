# 🎒 EduGo – Student App
---
A gamified, interactive educational mobile frontend designed for primary school students. It's built with Flutter and Dart. The app connects to a FastAPI and LLM-powered backend pipeline to deliver personalized learning paths, interactive quizzes and progress tracking in a child-friendly interface.
The mobile client interfaces directly with our backend REST API to display class-specific quizzes generated from teacher materials.

---
### 📦 Technologies

* `Flutter`
* `Dart`
* `REST API Integration`
* `FastAPI (Backend Target)`
* `JWT Authentication`
* `Cross-Platform (iOS & Android)`

---
### 🦄 Features

* **Child-Friendly Interface:** Vibrant, intuitive mobile UI specifically tailored for elementary school students.
* **Subject & Level Navigation:** Duolingo-Style Tree Navigation across subjects with clear visual progression.
* **Interactive Quizzes:** Dynamic quiz rendering supporting multiple choice and level-based question sets.
* **Gamification & Rewards:** Level progression, streak tracking and customizable avatar incentives. (in progress)
* **Synchronized REST Backend:** Secure JWT authentication and automated syncing with the teacher management portal.
